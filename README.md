# Air Shuji

カメラの前で、人差し指を筆にして空中に字を書く習字ツールです。
ブラウザだけで動きます（PC・スマホ対応）。

## 使い方

1. ページを開いて、カメラの使用を許可します。
2. カメラ画面のふちが緑（「ちょうどいい距離です」）になる位置に、手を構えます。
3. 「● 記録スタート」を押すと、3秒のカウントダウンのあと記録が始まります（秒数は変えられます）。
4. 人差し指で、空中に字を書きます。右（スマホでは下）の画面に、筆の線で描かれます。
5. 「PNG保存」で画像を、「🎬 工程を動画で保存」で書いている様子と線を並べた動画を保存できます。

## 筆の表現

- ゆっくり書くと太く濃く、すばやく払うと細く薄くなります。
- 書き始めと書き終わりは、筆の入り・抜きのように細くなります。
- 止めた所には、丸い墨溜まりができます。
- 「奥行きの効き」を上げると、指をカメラに近づけたときに太く濃く（筆を押し付けたように）なります。

## 調整できるもの

| 設定 | 内容 |
|---|---|
| 筆の太さ | ゆっくり書いたときの線の太さ |
| 奥行きの効き | 手をカメラに近づけたときに、どれだけ太くするか（0 で使わない） |
| 太さの変化 | 速さによって、どれだけ細くなるか |
| 濃淡調整 | 速さによって、どれだけ薄くなるか |
| 背景 | 単色か、グラデーション（上から下へ／左から右へ／斜め／中心から外へ） |
| 色 | 筆の色、背景、背景2（グラデーションの2色目） |

## うまく書くコツ

- 人差し指はカメラに向けず、上か横に向けて書きます。目の前に紙が立っていて、そこに書くイメージです。
- 腕を軽く伸ばしたくらいの距離で、手全体が画面に入るようにします。カメラ画面のふちの色と文字で、距離を案内します。
- 払いなどの速い所以外は、少しゆっくり書くと、指の位置が安定します。

## 仕組み

- 手の検出には [MediaPipe](https://github.com/google/mediapipe) を使っています。
- 映像はブラウザの中だけで処理されます。外部には送信しません。
- [Body Stroke](https://github.com/murakamimikiart-design/body-stroke) と同じコードで、習字のモードに固定したものです。

## ローカルで動かす

Mac では `起動.command` をダブルクリックすると、`http://localhost:8012/` で開きます。
